# UI 디자인 시스템 및 전 구간 100% 반응형 명세 (`ui-design-system.md`)

본 문서는 `book-mall`의 브랜드 메인 컬러(`#918a7d`) 기반 디자인 토큰 체계와 **`mall-front`(쇼핑몰 프론트) 및 `mall-admin`(관리기/백단 사이트) 양쪽 모두의 100% 반응형 웹 및 PC ↔ 모바일 레이아웃 구조 전환 기준**을 정의한다.

---

## 1. 브랜드 컬러 시스템 (Main Color: `#918a7d`)

도서 쇼핑몰의 종이 질감·서재 분위기에 어울리는 **웜 토프/그레이지(`#918a7d`)**를 프론트와 관리기 공통 핵심 브랜드 컬러로 사용한다. 프레임워크 기본 블루/인디고(`#3b82f6`, `#6366f1`, 기본 Bootstrap 파란색 등)는 절대 사용하지 않는다.

### 1.1 브랜드 컬러 스케일 (CSS Custom Properties 기준)

```css
:root {
  /* Brand Scale (Anchored at 500 = #918a7d) */
  --color-brand-50:  #f8f7f5; /* 페이지 기본 웜 오프화이트 서피스 */
  --color-brand-100: #efede9; /* 섹션 배경 / 은은한 강조 박스 */
  --color-brand-200: #dfdcd4; /* 카드·테이블 기본 보더 / 디바이더 */
  --color-brand-300: #cbc5b9; /* 입력창 기본 보더 / 비활성 요소 */
  --color-brand-400: #afa89b; /* 보조 아이콘 / 서브 장식 */
  --color-brand-500: #918a7d; /* [MAIN COLOR] 브랜드 시그니처 메인 컬러 */
  --color-brand-600: #787165; /* Primary 버튼 Hover / Active 인터랙션 */
  --color-brand-700: #5f594f; /* 밝은 배경 위 텍스트형 링크·강조 (명암비 4.5:1+ 보장) */
  --color-brand-800: #46423b; /* 관리기 사이드바 / 서브 헤딩 / 진한 내비게이션 */
  --color-brand-900: #2c2925; /* 본문 기본 잉크 컬러 (순수 #000 대신 눈이 편한 차콜 브라운) */

  /* Surface & Text */
  --color-surface:       #ffffff;
  --color-surface-muted: #f8f7f5;
  --color-text-primary:  #2c2925;
  --color-text-secondary:#666057;

  /* Editorial Semantic Colors (저채도 톤앤매너 조화) */
  --color-success: #4d7c60; /* 배송완료 / 재고충분 / 사용가능 ID */
  --color-warning: #b57d3b; /* 재고임박 / 배송준비중 */
  --color-danger:  #b34a42; /* 품절 / 입력오류 / 주문취소 */
  --color-info:    #5c768d; /* 운송장 조회 / 배송중 안내 */
}
```

### 1.2 가독성 및 명암비(Contrast) 규칙
- `#918a7d`(`brand-500`) 배경 위에 흰색(`#ffffff`) 텍스트를 올릴 때는 `font-weight: 600` 이상을 적용하고, Hover/Focus 시 `brand-600`(`#787165`)으로 전환하여 시인성을 높인다.
- 흰색/밝은 배경(`#ffffff`, `#f8f7f5`) 위에 작은 본문 글씨(14px 이하)로 브랜드 컬러를 쓸 때는 흐릿해 보이지 않도록 `brand-700`(`#5f594f`) 이상을 사용한다.

## 2. 반응형 대원칙: 단순 축소가 아닌 "PC ↔ 모바일 레이아웃 구조 전환"

프론트(`mall-front`)와 관리기(`mall-admin`)의 모든 화면은 **`320px`(소형 모바일) ~ `768px`(태블릿) ~ `1440px+`(PC 데스크톱)** 전 구간에서 가로 스크롤 깨짐(`overflow-x` 넘침) 없이 **100% 반응형**으로 동작해야 한다.
특히 화면 폭만 좁히는 방식이 아니라, **뷰포트 구간에 따라 앱 골격(App Shell)·내비게이션·데이터 표현·액션바의 레이아웃 구조 자체가 전환(Structural Adaptation)**되어야 한다.

### 공통 인터랙션 기준 (프론트 & 관리기 공통)
- **터치 타깃**: 모바일/태블릿 구간에서 모든 버튼·체크박스·행 액션·페이지네이션은 최소 **`44 x 44px`** 이상 확보한다.
- **모바일 폼 자동 확대 방지**: 모바일에서 `<input>`, `<select>`, `<textarea>`의 글자 크기는 최소 **`16px`(`1rem`) 이상**으로 지정한다.
- **노치/홈바 영역 대응**: 모바일 하단 고정 바(하단 탭바 또는 하단 액션바)에는 `padding-bottom: env(safe-area-inset-bottom)`을 반드시 반영한다.

## 3. `mall-front` (쇼핑몰 프론트) PC ↔ 모바일 구조 전환 규격

| 화면 / 구성요소 | PC 데스크톱 구조 (`>= 1024px`) | 모바일 구조 (`< 768px`, 태블릿은 중간 단계 적응) |
| :--- | :--- | :--- |
| **글로벌 App Shell** | 상단 유틸바 + 풀 헤더(로고·조건통합검색·마이메뉴) + 수평 전체 카테고리 GNB 바 | 상단 컴팩트 앱바(로고·검색 아이콘·장바구니 배지) + 슬라이드 카테고리 드로어 + **하단 탭 네비게이션(`홈·분야·베스트·보관함·마이`)** |
| **도서 목록 / 검색** | **좌측 고정 필터 사이드바** + 우측 요약 리스트(다중 체크박스 일괄담기 바 + 우측 액션 버튼열) 또는 4~5열 그리드 | **상단 가로 스크롤 필터 칩 & 정렬 바텀시트** + 1열 서점형 컴팩트 카드(좌측 `3:4` 표지 + 우측 서지/출고배지 + 카드 하단 버튼) 또는 2열 그리드 |
| **도서 상세** | 상단 **2단 분할**(좌측 대형 표지 + 우측 서지/가격/출고안내/구매버튼) + 스크롤 시 우측 미니 주문 패널 유지 | **단일 컬럼 수직 스택**(표지 → 핵심 서지/가격/출고일 → 가로 스크롤 Sticky 탭) + **하단 고정 구매 액션바(`[장바구니] / [바로구매]`)** |
| **장바구니 / 주문서** | **2단 분할**(좌측 도서 목록·배송지 폼 `68%` + 우측 Sticky 결제금액 요약 사이드바 `32%`) | **1열 수직 카드 스택** + 무료배송 게이지 상단 배치 + **하단 고정 최종 결제금액 & `[주문/결제하기]` 바** |
| **주문내역 / 배송조회** | 다열 주문 요약 테이블 + **가로형 배송 단계 프로그레스 바** | **주문별 구조화 카드 리스트** + **세로형 택배 이동 타임라인 스텝** |

## 4. `mall-admin` (관리기 / 백단 사이트) PC ↔ 모바일 구조 전환 규격

운영자가 사무실 데스크톱뿐 아니라 물류 현장·외부에서 스마트폰이나 태블릿으로 접속해 **도서 등록/재고 수정, 운송장 입력/출고 처리, 고객/리뷰 관리**를 완벽히 수행할 수 있도록 관리기 전체 화면도 100% 반응형 구조 전환을 강제한다.

| 관리기 구성요소 | PC 데스크톱 구조 (`>= 1024px`) | 모바일 구조 (`< 768px`) / 태블릿 (`768~1023px`) |
| :--- | :--- | :--- |
| **관리기 App Shell** | **좌측 고정 사이드바(`240~260px`)** 상시 노출 + 상단 브레드크럼/관리자 바 + 우측 와이드 작업 영역 | 좌측 고정 사이드바 완전 숨김 → **상단 모바일 관리 헤더(햄버거 오프캔버스 슬라이드 드로어 메뉴 + 현재 화면명)** + 풀폭 본문 (태블릿은 접이식 아이콘 레일/드로어) |
| **대시보드** | 상단 **4열 KPI 요약 카드**(금일주문/미출고/품절임박/취소요청) + 하단 **2열 현황 그리드** | **2x2 컴팩트 KPI 카드 그리드** + **1열 수직 현황 카드 스택** |
| **검색 · 필터 툴바** | 기간·상태·카테고리·키워드 **다중 인라인 수평 필터 바** | 상단 핵심 검색창만 기본 노출 + **`[상세 필터 (적용 N개)]` 접이식 아코디언/바텀시트**로 접어 좁은 화면 깨짐 방지 |
| **데이터 목록 (`<table>` → `Card` 전환)** | 고밀도 다열 **`<table>`** (일괄 체크박스, 정렬 헤더, 상태 배지, 인라인 관리 버튼) | **가로 스크롤 테이블 방치 금지 → 모바일 운영 액션 카드(Admin Action Card) 리스트로 구조 전환**:<br>- **상품 카드**: 표지 썸네일 + 도서명/ISBN + 판매가/재고수량 배지 + 하단 `[재고변경]` `[수정]` 버튼<br>- **주문/출고 카드**: 주문번호/일시 + 주문·배송상태 배지 + 수령인(마스킹)/금액 + 하단 `[운송장 등록]` `[상세]` 버튼<br>- **고객/리뷰 카드**: 마스킹 식별정보 + 상태 배지 + 하단 `[상세열람]` / `[블라인드]` 버튼 |
| **등록/수정 폼 & 모달** | **2~3열 그리드 입력 섹션**(예: 정가·할인율·판매가 병렬 배치) 및 화면 중앙 모달 | **1열 풀폭 수직 입력 폼** + 중앙 모달 대신 **모바일 풀스크린 시트/바텀시트** 전환 + **하단 고정 `[저장 / 출고확정]` 액션바** |

## 5. 반응형 완료 검증 기준 (프론트 & 관리기 공통)

`mall-front` 또는 `mall-admin` 화면 작업 완료 시 반드시 아래 3개 대표 뷰포트 기준으로 레이아웃 전환과 가로 스크롤 유무(`document.documentElement.scrollWidth <= window.innerWidth`)를 모두 검증한다.
1. **Mobile**: `360 x 800` (및 최소폭 `320px` 깨짐 점검 — 사이드바 드로어·모바일 카드 뷰·하단 액션바 전환 확인)
2. **Tablet**: `768 x 1024` (중간 그리드 및 접이식 네비게이션 확인)
3. **Desktop (PC)**: `1440 x 900` (사이드바/GNB·다단 분할·데이터 테이블 확인)
