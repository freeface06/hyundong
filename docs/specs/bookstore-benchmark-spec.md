# 온라인 서점 벤치마킹 레퍼런스 명세 (`bookstore-benchmark-spec.md`)

`book-mall`의 정보구조(IA), 상품 표현, 검색·탐색, 장바구니·출고 흐름은 국내 대표 온라인 서점인 **YES24(예스24)**와 **알라딘(Aladin)**의 검증된 구조를 레퍼런스로 삼으며, 판매 도메인은 **한의학 전문 학술·임상 서적(레퍼런스: 현동학당 · 도서출판 물고기 `hyundong.co.kr`)**에 특화하여 구성한다. 단, 초기 구축 목적("기본적인 도서 쇼핑몰 구축")에 맞게 핵심 커머스 기능만 채택하고 비본질적 부가사업은 명확히 제외한다.

---

## 1. 벤치마킹 채택 범위 vs 제외 범위 (Scope Guardrail)

| 구분 | 채택 항목 (필수/권장 구현) | 제외 항목 (오버엔지니어링 금지) |
| :--- | :--- | :--- |
| **도서 상품/가격** | ISBN-13·쪽수·판형 등 표준 서지정보, **도서정가제 가격표시(정가 · 최대 10% 할인가 · 5% 적립안내)**, 목차/저자소개/출판사서평 분리 | 전자책(eBook) 뷰어/DRM, 오디오북 스트리밍, 해외원서 항공직배송 특송 |
| **탐색/큐레이션** | 다단계 분야 카테고리(대·중·소), **베스트셀러 순위**, **신간도서**, **오늘의 책(MD 추천)**, 제목/저자/출판사/ISBN 조건 검색 | 공연/티켓/영화 예매, 중고매장(오프라인 재고)/개인 간 중고장터 |
| **목록/구매 UX** | **요약 리스트형(다중 체크 일괄 장바구니 담기) + 그리드형 전환**, **출고예정일 안내 배지(당일/익일 출고)**, **보관함(찜)**, 무료배송 잔여금액 게이지 | 복잡한 제휴카드 청구할인 계산기, 상품권/기프티콘 발행소 |
| **커뮤니티/리뷰** | 구매자 배지가 포함된 **별점(5점 만점) + 한줄평/독자리뷰** | 블로그/페이퍼 SNS, 독서모임 개설 플랫폼 |

## 2. `mall-front` 화면별 벤치마킹 설계 기준 (YES24 · 알라딘 패턴)

### 2.1 공통 헤더 · 검색 · GNB
- **통합 검색창**: 검색 조건 드롭다운(`통합검색` / `도서명` / `저자·역자` / `출판사` / `ISBN`) + 키워드 입력 (모바일에서는 상단 검색 아이콘 터치 시 풀폭 검색 드로어/바 전개)
- **핵심 GNB 구성**: `[분야보기(전체 카테고리)]` · `[베스트셀러]` · `[신간도서]` · `[MD 추천]`
- **표준 도서 대분류 초기 시드 (한의학 전문 서점 특화)**:
  1. `동의보감 · 경전직역` (동의보감 전4권 세트 및 내경·외형·잡병 낱권, 난경본의 등)
  2. `진단학 · 맥진학` (찬도방론맥결집성, 사진심법요결 등)
  3. `방제학 · 실전처방집` (현동처방집 상·하 세트 등)
  4. `임상의안 · PBL 강독` (현동의감 전5권 세트, 동의보감 내경편 강의집, PBL 임상토론집 등)
  5. `인체생리 · 양생의철학` (하늘기운을 품고 있는 우리 몸, 하늘기운을 닮아가는 우리 몸 등)
- **한의학 서적 특화 표현 요소**: 전집/양장 세트(`세트 구성`)와 `낱권` 구분 표기, 한자 원제 병기, 출판사 직판 할인율 및 `50,000원 이상 무료배송(미만 시 3,500원)` 정책 지원

### 2.2 메인 페이지 (`Home`)
1. **메인 에디토리얼 배너 / 오늘의 책**: 관리기에서 지정한 추천 도서 표지와 핵심 추천사 카피 노출 (`#918a7d` 브랜드 웜톤 배경과 조화)
2. **베스트셀러 랭킹 섹션**: `1위 ~ 10위` 순위 넘버링 배지 + 표지 + 도서명 + 저자 (전체/분야별 탭 전환 지원)
3. **주목할 만한 신간**: 최근 출간일 기준 신간 큐레이션 리스트
4. **MD의 선택 (화제의 책)**: 운영자가 선정한 테마별 도서 카드 노출

### 2.3 분야별 목록 및 검색 결과 페이지 (서점 특화 리스트 UX)
일반 쇼핑몰의 단순 바둑판 배열을 넘어, YES24/알라딘에서 검증된 **서점형 요약 리스트 뷰**를 기본 제공한다.
- **정렬 옵션**: `인기/판매량순` · `신상품(출간일)순` · `낮은가격순` · `높은가격순` · `리뷰많은순` · `평점순`
- **필터 옵션**: 하위 카테고리 선택, `품절/절판 제외` 토글
- **요약 리스트 아이템 필수 노출 요소**:
  1. 좌측: 선택 체크박스(데스크톱/태블릿 일괄 담기용) + `3:4` 도서 표지
  2. 중앙: `[분야 태그]` 도서명(부제) · `저자 | 역자 | 출판사 | 출간년월` · **`판매가 (정가 대비 N%↓) + 적립금 안내`** · **출고 예정 안내 배지**(예: `오늘 출고 예정` / `일시품절`) · 별점 및 리뷰 수 + 책소개 2줄 요약
  3. 우측(모바일은 카드 하단): `[장바구니]` · `[바로구매]` · `[보관함(찜)]` 액션 버튼
- **상/하단 일괄 액션바**: 체크한 여러 권의 도서를 한 번에 `[선택상품 장바구니 담기]` / `[보관함 담기]` 지원

### 2.4 도서 상세 페이지
- **상단 구매 정보 패널**:
  - 고해상도 표지, 제목/부제, 저자·역자·출판사·출간일 링크
  - 정가, 판매가(할인율), 기본 적립 포인트 안내
  - 배송비 안내(`20,000원 이상 무료배송, 미만 시 3,000원`) 및 **마감시간 기준 출고 예정일 안내**(예: 평일 15시 이전 결제 시 당일 출고 진행)
  - 수량 선택기 + 합계 금액 + `[장바구니]` / `[바로구매]` / `[보관함]` (모바일에서는 하단 Sticky CTA 바와 연동)
- **하단 상세 앵커 탭 (스크롤 시 상단 고정)**:
  1. **품목정보**: 출간일, 쪽수, 판형/크기, 무게(선택), `ISBN-13` 테이블
  2. **책소개 & 출판사 서평**: 에디토리얼 본문 가독성 최적화(`line-height: 1.75`)
  3. **목차 (`Table of Contents`)**: 접기/펼치기 지원 (전문서·실용서 구매 결정 핵심 요소)
  4. **저자 및 역자 소개**: 저자 약력 표시
  5. **독자 리뷰 / 한줄평**: 평점 분포 요약 + 실구매자(`구매자` 배지) 한줄평/리뷰 목록 및 작성 폼
  6. **배송/교환/반품 안내**: 도서 파본/오배송 교환 및 단순변심 반품 비용 기준 명시

### 2.5 장바구니 · 보관함(찜) · 마이페이지
- **무료배송 프로그레스 바**: YES24/알라딘 장바구니처럼 현재 선택 도서 금액 기준으로 *"무료배송까지 **3,500원** 남았습니다 (`20,000원` 이상 무료)"* 또는 *"무료배송 대상 주문입니다"*를 실시간 계산해 표시한다.
- **보관함(`Wishlist`)**: 당장 구매하지 않는 책을 담아두고 언제든 장바구니로 이동할 수 있는 개인 서재형 찜 목록을 제공한다.
- **마이페이지 대시보드**: 상단에 진행 중 주문 단계별 카운트(`결제완료` → `상품준비중` → `배송중` → `배송완료`)를 한눈에 보여주고, 주문별 운송장 배송추적·취소·리뷰 작성으로 즉시 연결한다.

## 3. `mall-admin` (관리기) 벤치마킹 운영 기능 기준

1. **도서 상품 등록/수정 (서점 MD 표준 폼 · 공통코드 연동)**:
   - 기본 서지: **도서 분야(`BOOK_CATEGORY`) 및 단권/세트 구분(`BOOK_TYPE`) 공통코드 드롭다운 연동**, 도서명/부제, 저자/역자, 출판사, 출간일, `ISBN-13`(중복 체크 및 13자리 숫자 검증), 쪽수, 크기/판형
   - 가격 및 재고: 정가 입력 시 기본 할인율 자동 계산, 재고 수량, 판매 상태(`BOOK_SALE_STATUS` 공통코드 연동: `ON_SALE`, `PREORDER`, `OUT_OF_STOCK`, `DISCONTINUED`)
   - 상세 콘텐츠 분리 입력: WYSIWYG 웹 에디터 `책소개`, `목차`, `저자소개`, `출판사 서평`
   - 진열 플래그: `MD 추천(오늘의 책)` 지정 여부
2. **분류 · 선택항목 공통코드 통합 관리 (`/admin?sec=codes`)**:
   - 하드코딩 없이 도서 분야(`BOOK_CATEGORY`), 단권/세트 구분(`BOOK_TYPE`), 판매 상태(`BOOK_SALE_STATUS`), 회원 구분(`MEMBER_GRADE`), 문의·게시판 분류(`BOARD_CATEGORY`), 택배사·조회 주소(`CARRIER_CODE`)의 코드 추가·표시명 수정·노출 순서 조정·사용/숨김 제어를 지원한다.
3. **메인 배너 및 큐레이션 진열 관리**:
   - 쇼핑몰 메인 배너 및 추천 도서 섹션 노출 순서/활성화 제어
4. **주문 · 출고 · 운송장 번호 관리**:
   - 당일 출고 대상(`PAID` / `PREPARING_SHIPMENT`) 조회 → 포장준비 전환 → 택배사 선택 및 운송장 번호 등록(`SHIPPED`)까지만 관리 (출고 이후 상세 배송 위치는 프론트에 안내된 택배사 조회 페이지 주소로 고객이 직접 조회)
5. **고객 관리 및 독자 리뷰 관리**:
   - 마스킹된 고객 목록 조회 / 감사로그 기반 상세 조회 / 계정 상태 제어
   - 도서 리뷰/한줄평 조회 및 욕설·스팸 리뷰 블라인드(`HIDDEN`) 처리
